## 💡 Sobre el Proyecto

**CampoRed** es una plataforma de e-commerce agrícola que conecta directamente a los productores de **Sonsón y San Carlos** con restaurantes, tiendas y mayoristas del Oriente Antioqueño. Nuestro objetivo es eliminar intermediarios, reduciendo la cadena de distribución local en hasta un 40%.

**Impacto esperado:** 
- 📈 **Productores:** Aumentan significativamente sus márgenes de ganancia.
- 🥗 **Compradores:** Acceden a productos frescos con trazabilidad clara de cosecha y logística coordinada.

---

## 📦 Nuestros Repositorios

El ecosistema de CampoRed está dividido en dos repositorios principales (Arquitectura Desacoplada):

| Repositorio | Descripción | Tecnologías Clave |
|-------------|-------------|-------------------|
| ⚙️ [**campored-backend**](https://github.com/campored-project/campored-backend) | API RESTful que gestiona la lógica de negocio, usuarios, fincas, catálogo de ofertas y pedidos. | `Java 21`, `Spring Boot 3`, `PostgreSQL`, `JWT` |
| 💻 [**campored-frontend**](https://github.com/campored-project/campored-frontend) | Interfaz de usuario web sectorizada por roles (Productor y Comprador). | `React 18`, `Vite`, `Tailwind CSS` |

## 🚀 Módulos del MVP (Semestre 2026-2)

1. **Sprint 1:** Autenticación segura, JWT y perfiles sectorizados (Productor/Comprador).
2. **Sprint 2:** Catálogo de ofertas (CRUD), gestión del ciclo de cosecha y filtros inteligentes.
3. **Sprint 3:** Checkout del pedido, logística de entrega, contacto directo por WhatsApp y Dashboard.
